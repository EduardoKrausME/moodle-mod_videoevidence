# Video Evidence

`mod_videoevidence` is a Moodle activity module in which students answer questions using evidence selected directly from
a video.

## Features

- Video sources: Moodle upload, direct URL/HLS, YouTube and Vimeo (including unlisted Vimeo hash URLs).
- Real watched-progress tracking based on continuous played segments rather than the furthest position reached.
- Playback resume and visual watched timeline.
- Questions that request a single moment or a time interval.
- One or multiple evidence selections per question.
- Written justification for every selected evidence item.
- Optional expected time range with tolerance for automatic selection scoring.
- Independent grading weights for correct excerpt selection, justification quality and minimum evidence quantity.
- Manual/hybrid grading with feedback.
- Moodle gradebook integration.
- Custom activity completion requiring mandatory evidence questions.
- Per-student reporting with questions answered, evidence selected, submissions, grade and watched percentage.
- Backup/restore and Privacy API support.
- English and Brazilian Portuguese language packs.

## Requirements

Moodle 4.4 or later.

## Installation

Install the folder as `mod/videoevidence` and complete the Moodle upgrade process.
